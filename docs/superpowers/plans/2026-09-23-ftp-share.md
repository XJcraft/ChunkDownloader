**Goal:** Add FTP as a config-switchable download source alongside the existing OneDrive share, generating
`ftp://user:pass@host/path` links in `tellraw` so players can open them with their local FTP client.

**Architecture:** Add `ShareMethod` enum + FTP fields to `AzureConfig`, add a new `FtpUtil` class that only does
string/URL building (no FTP client dependency), and branch inside `CDCommand.get()` to call either
`OneDriveUtil.getFileDownloadUrl` or `FtpUtil.buildUrl`. Default stays `ONEDRIVE` so existing deployments are
unaffected.

**Tech Stack:** Java 8, Spigot 1.13 API, Maven shade, SimpleSpigot `@RConfig` for config loading, JUnit 4.13.2 +
surefire 3.2.5 for unit tests (surefire must be pinned in pom.xml — version 3.0.0 artifacts are broken in the local
repo).

package org.xjcraft.chunkdownloader;

import org.xjcraft.chunkdownloader.config.AzureConfig;

import java.io.UnsupportedEncodingException;
import java.net.URLEncoder;

public class FtpUtil {

    public static String buildUrl(String relativePath) {
        AzureConfig cfg = AzureConfig.config;

        String user = encode(cfg.getFtpUser());
        String pass = encode(cfg.getFtpPassword());

        String root = cfg.getFtpRoot();
        if (root.endsWith("/")) {
            root = root.substring(0, root.length() - 1);
        }
        String path = relativePath.startsWith("/") ? relativePath.substring(1) : relativePath;

        String fullPath = root.isEmpty() ? path : root + "/" + path;

        return "ftp://" + user + ":" + pass + "@"
                + cfg.getFtpHost() + ":" + cfg.getFtpPort()
                + "/" + fullPath;
    }

    private static String encode(String s) {
        try {
            return URLEncoder.encode(s, "UTF-8").replace("+", "%20");
        } catch (UnsupportedEncodingException e) {
            throw new RuntimeException(e);
        }
    }
}
```

@RCommand(value = "my", desc = "获取我所在区块", sender = RCommand.Sender.PLAYER)
public void get(CommandSender player) {
    Chunk chunk = ((Player) player).getLocation().getChunk();
    HashMap<String, String> placeholder = new HashMap<String, String>() {{
        put("x", (chunk.getX() >> 5) + "");
        put("y", (chunk.getZ() >> 5) + "");
    }};
    String fname = StringUtil.applyPlaceHolder(AzureConfig.config.getFname(), placeholder);
    String p = AzureConfig.config.getWorlds().getOrDefault(chunk.getWorld().getName(), chunk.getWorld().getName());
    final String path = String.format(p, fname);
    System.out.println("get url for: " + path);

    plugin.getServer().dispatchCommand(plugin.getServer().getConsoleSender(),
            String.format("tellraw %s [\"\",{\"text\":\"正在查询文件：%s\",\"color\":\"white\"}]",
                    player.getName(), fname));

    plugin.getServer().getScheduler().runTaskAsynchronously(plugin, new Runnable() {
        @Override
        public void run() {
            if (AzureConfig.config.getShareMethod() == AzureConfig.ShareMethod.FTP) {
                String url = FtpUtil.buildUrl(path);
                plugin.getServer().getScheduler().runTask(plugin, () ->
                        plugin.getServer().dispatchCommand(plugin.getServer().getConsoleSender(),
                                String.format("tellraw %s [\"\",{\"text\":\"点此下载我所在的区块\",\"color\":\"blue\",\"bold\":false,\"underlined\":true,\"clickEvent\":{\"action\":\"open_url\",\"value\":\"%s\"}}]",
                                        player.getName(), url))
                );
                return;
            }

            String url = OneDriveUtil.getFileDownloadUrl(path);
            plugin.getServer().getScheduler().runTask(plugin, () ->
                    plugin.getServer().dispatchCommand(plugin.getServer().getConsoleSender(),
                            String.format("tellraw %s [\"\",{\"text\":\"点此下载我所在的区块\",\"color\":\"blue\",\"bold\":false,\"underlined\":true,\"clickEvent\":{\"action\":\"open_url\",\"value\":\"%s\"}}]",
                                    player.getName(), url))
            );

            List<OneDriveUtil.VersionUrl> downloadUrls = OneDriveUtil.getFileVersionDownloadUrls(path);
            plugin.getServer().getScheduler().runTask(plugin, () -> {
                plugin.getServer().dispatchCommand(plugin.getServer().getConsoleSender(),
                        String.format("tellraw %s [\"\",{\"text\":\"历史记录\",\"color\":\"dark_gray\",\"bold\":true}]",
                                player.getName()));
                for (OneDriveUtil.VersionUrl pair : downloadUrls) {
                    String time = pair.getTime();
                    String version = pair.getUrl();
                    plugin.getServer().dispatchCommand(plugin.getServer().getConsoleSender(),
                            String.format("tellraw %s [\"\",{\"text\":\"%s\",\"color\":\"blue\",\"bold\":false,\"underlined\":true,\"clickEvent\":{\"action\":\"open_url\",\"value\":\"%s\"}}]",
                                    player.getName(), time, version));
                }
            });
        }
    });
}
```

## Notes for deployers

To switch to FTP, set these values in `azure.yml` on the server:

```yaml
shareMethod: FTP
ftpHost: "your.ftp.host"
ftpPort: 21
ftpUser: "readonly_user"
ftpPassword: "readonly_password"
ftpRoot: ""        # leave empty if FTP directory mirrors OneDrive layout
ftpPassive: true
```

In FTP mode the history-version list is not shown. OneDrive config fields (`clientId`, `clientSecret`, etc.) are ignored
but can be left in place.
